# دفتر مطالعهٔ بازیابی اطلاعات

## استفاده
۱. کل فایل ZIP را از حالت فشرده خارج کنید.
۲. فایل `index.html` را در مرورگر باز کنید؛ نیازی به نصب یا اجرای Python نیست.
۳. موضوع را جست‌وجو کنید یا یکی از هفت فصل را انتخاب کنید.

- هفت درس‌نامه با مثال و ۲۸ پرسش کوتاه (چهار پرسش در هر فصل)
- نمایش تعاملی پورتر کلاسیک در فصل سوم، با پنج واژهٔ آماده و دکمه‌های قبل، بعد و شروع دوباره
- جست‌وجوی عنوان و متن درس‌ها، با یکسان‌سازی ی/ک عربی و فارسی
- صفحهٔ `review.html` برای مرور و `resources.html` برای منابع اصلی
- گزینهٔ چاپ / ذخیرهٔ PDF در هر فصل (از پنجرهٔ چاپ مرورگر)
- ثبت مطالعه در انتهای فصل؛ این داده فقط در مرورگر شما ذخیره می‌شود.

در حالت بازکردن مستقیم فایل (`file://`)، پیشرفت علاوه بر تلاش برای ذخیره در مرورگر، از طریق آدرس لینک‌های داخلی و همان زبانه میان صفحات منتقل می‌شود. برای حفظ وضعیت از لینک‌های داخل سایت استفاده کنید؛ بازکردن دوبارهٔ فایل خام در زبانه‌ای تازه، در همهٔ مرورگرها تضمین‌شده نیست. برای ثبت پیشرفت قابل‌اتکاتر، سایت را روی یک میزبان استاتیک قرار دهید یا در این پوشه دستور `python -m http.server 8000` را اجرا و `http://localhost:8000` را باز کنید. این کار برای خواندن درس‌ها الزامی نیست. پیشرفت میان دستگاه‌ها همگام نمی‌شود و با پاک‌کردن داده‌های مرورگر از بین می‌رود.

محتوا، جست‌وجو، تصاویر و PDFها محلی هستند. فقط فونت وزیرمتن در صورت دسترسی از اینترنت دریافت می‌شود؛ بدون اینترنت از فونت جایگزین استفاده می‌شود. صفحات اسلایدی قدیمی در پوشهٔ `html` صرفاً آرشیو هستند و ممکن است وابستگی‌های اینترنتی خود را داشته باشند.

## اشتراک‌گذاری
کل ZIP را برای دوستان بفرستید، نه فقط `index.html`. برای انتشار آنلاین، کل ساختار پوشه را روی یک میزبان استاتیک کپی کنید. backend، حساب کاربری و پایگاه داده لازم نیست.

## ویرایش و ساخت مجدد (برای توسعه‌دهنده)
- `course.md`: متن پایهٔ اصلاح‌شده
- `build_course.py`: توضیحات تکمیلی، مثال‌ها، خودآزمایی‌ها و تولید صفحات
- `site.js` و `topics.js`: رابط جست‌وجو و دادهٔ تولیدشدهٔ آن
- `progress.js`: ذخیرهٔ پیشرفت و انتقال وضعیت میان فایل‌های محلی
- `practice.json`: پرسش‌های افزوده و پاسخ‌های خودآزمایی
- `porter.js`: ردگیری‌های آموزشیِ از پیش تعریف‌شدهٔ پورتر کلاسیک (نه موتور عمومی برای ورودی آزاد)
- `site.css` و `course.css`: ظاهر سایت و حالت موبایل/چاپ
- `bin`: منابع ارسالی اصلی، بدون تغییر
- `html`: اسلایدهای نسخهٔ قبلی، برای رجوع

برای بازسازی درس‌نامه‌ها و فهرست جست‌وجو:

```sh
python -m pip install -r requirements.txt
python build_course.py
```

این دستور `chapter-*.html`، `topics.js`، `resources.html` و `review.html` را بازنویسی می‌کند؛ تغییرات محتوایی را در فایل‌های مبنا انجام دهید، نه فقط HTML خروجی. `index.html` مستقل از مولد است. ابزار قدیمی `build_site.py` و فهرست قبلی در `archive` نگهداری شده‌اند و برای ساخت نسخهٔ جدید استفاده نمی‌شوند.

## حدود محتوا
این سایت بازنویسی آموزشی منابع ارسالی است، نه رونویسی کلمه‌به‌کلمه یا پوشش کل سرفصل‌های رشته. مثال‌های تکمیلی به متن افزوده شده‌اند. اصلاحات مهم و اشتباه‌های رایج در صفحهٔ مرور آمده‌اند. تصاویر و نسخهٔ اولیه برای تطبیق در دسترس‌اند.
